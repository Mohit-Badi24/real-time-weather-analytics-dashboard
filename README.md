# 🌦️ Real-Time Weather Analytics Dashboard

An interactive single-page Power BI dashboard designed to provide a comprehensive view of weather conditions, forecasts, rainfall probability, air quality, and other weather-related metrics.

## 📊 Dashboard Preview

![Weather Analytics Dashboard](screenshots/weather-dashboard.png)

## ✨ Features

- Current weather conditions
- Multi-day weather forecast
- Temperature visualization
- Chance of rain analysis
- Air Quality Index (AQI)
- Pollutant-level monitoring
- Sunrise and sunset information
- Humidity
- Wind speed
- Visibility
- Atmospheric pressure
- UV Index
- Precipitation
- Weather comparison across multiple cities

## 🛠️ Tools & Technologies

- Power BI
- Weather API
- Power Query
- DAX
- Data Visualization
- API Integration

## 📈 Dashboard Insights

The dashboard provides an interactive view of weather conditions and related environmental metrics in a single-page interface. Users can quickly view current conditions, upcoming forecasts, rainfall probability, air quality, and other important weather indicators.

## 📁 Project Files

- `Weather_Analytics_Dashboard.pbix` — Power BI dashboard file
- `screenshots/weather-dashboard.png` — Dashboard preview

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Configure the required data/API connection if necessary.
4. Refresh the data to retrieve the latest information.
